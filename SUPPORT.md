# Support

[简体中文](SUPPORT.zh-CN.md)

Use GitHub Discussions for usage questions and Issues for reproducible defects.
Include the operating system, Git version, tool version, exit status, output
format, and a synthetic minimal reproduction. State whether submodule or tracked
status checks were enabled.

Never publish real absolute paths, repository names, branch names, commit IDs,
lock reasons, configuration values, credentials, or unsanitized Git output.
The default redaction is defense in depth, not a substitute for reviewing a
report before sharing it.
